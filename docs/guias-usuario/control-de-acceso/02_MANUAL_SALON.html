INVITACIONESPREMIUM

Para el encargado del salón, coordinación y recepción

Guía para recibir a tus invitados

Sigue la parte que corresponda a tu evento: una lista con nombres o pases numerados.

El encargado o coordinador usa su cuenta. Recepción abre únicamente el enlace privado que le entrega el encargado para ese evento. Las franjas oscuras de las imágenes protegen contraseñas, enlaces y la vista de cámara.
